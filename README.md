# 学径（Xuejing）Windows 桌面端

面向本科生的本地优先学习中枢：聚合 Blackboard、Gradescope、课程资料、作业截止时间与期末复习工作流，帮助学生少在多个平台之间切换，也能从真实课件出发梳理知识与复习进度。

当前正式版：`1.2.1`。本项目是 Electron + React + TypeScript 的 Windows 桌面应用。

## 免安装测试

不需要安装。直接双击运行：

```text
release\win-unpacked\学径.exe
```

发布归档同时提供 `release/Xuejing-1.2.1-win-x64-portable.zip`，解压后运行其中的 `学径.exe` 即可。

首次运行后，按需连接 Blackboard 或 Gradescope；学校统一身份认证、验证码与二次认证仍由用户在登录窗口中完成。

## 当前能力

- 同步 Blackboard 课程、内容目录、文件、外链和作业入口；保留课程原有目录结构并支持本地缓存、自动缓存与资料库迁移。
- 同步 Gradescope 的学期、课程、作业、提交入口和可见的提交/成绩状态；Blackboard 作业与 Gradescope 作业统一进入作业中心。
- 新增学习收件箱：平台同步后集中展示新课程、新资料、新作业、DDL、提交状态和成绩变化，支持未读、已读、归档、来源筛选与原内容跳转；重复同步不会重复生成相同消息。
- 支持可选 SMTP 邮箱通知。用户可以自行配置发件邮箱和收件地址，分别控制同步变化摘要与 DDL 临近提醒；邮箱密码或应用专用密码使用 Windows 安全存储加密，默认不启用。
- 设置中心支持可选后台自动同步：可分别同步 Blackboard/Gradescope，选择 30 分钟、1 小时、3 小时或 6 小时间隔，并配置启动同步与跨午夜免打扰时段。登录过期后停止请求并写入学习收件箱，重新登录后恢复。
- DDL 邮件支持提前 1/3/5/7 天多选阈值。同一作业、当前 DDL 和阈值只提醒一次；错过多个较早阈值时只发送当前最近的一档，多项作业合并为一封摘要邮件。
- 识别和管理 DDL，支持状态修正、手动完成、提交页跳转和应用运行期间的 Windows 桌面提醒；Gradescope 作业由用户在网页下载后手动导入，应用会缓存到该作业专属目录，并按用户请求解析附件文本交由 AI 匹配课程知识点、确认后带入复习。
- 解析 PDF、DOCX、PPTX、旧版 PPT 与 LaTeX；支持扫描 PDF 的本地单份/批量 OCR，以及可选的自适应 AI 精炼。支持原件输入的 API 直接分析文件，DeepSeek/Gemini 等对话接口自动使用本地分页兼容流程。教材/参考资料只在本地解析、检索和阅读。
- AI 设置提供 OpenAI / GPT、DeepSeek、Google Gemini 和自定义接口预设，可动态读取模型列表并检测对话、Files 与 Responses 能力，避免批量任务反复请求不存在的文件端点。
- 知识库可区分真正的新旧版本、同名不同 Blackboard 资源与来源冲突；默认使用同一来源的最新相近版本，允许手动切换，并按文件哈希恢复各版本 AI 结果。
- 构建“资料级主题 → 课程知识点 → 来源资料”的知识库和可缩放知识图谱，支持单课程与全部课程聚合、知识点自评。
- 提供期末复习会话：系统规划或自选资料/知识点、AI 路线建议一键应用、学习进度持久化、番茄钟、课程问答和沉浸模式。
- 在复习会话内预览 PDF、DOCX 与 PPTX；旧 `.ppt` 以结构化文本与系统默认应用打开作为降级方案。
- 记录每日学习日记与情绪；成长面板按课程展示“接触 → 理解确认 → 测试验证”三层证据、7/30 天活动趋势、测试表现和当前薄弱资料，并可一键进入针对性复习。
- 成长面板新增 60 项可收集成长成就与 12 项高价值里程碑；成就由真实复习、测试、专注、作业、日记和课程完成证据触发，历史数据仅回填一次且不会重复弹出。
- 新增月度学习日历，以 6×7 月历聚合复习、测试、作业、专注、日记和成就记录，支持按课程/类型筛选、查看日期详情，并可补写、编辑或删除任意日期的学习日记。
- 成就反馈提供普通卡片、稀有粒子和里程碑烟花三级庆祝；设置中可切换完整、轻量或关闭，复习会话进行中会延迟展示，避免打断阅读。
- 提供集中设置中心、浅色/深色/毛玻璃/跟随系统主题、可关闭动效与启动动画，以及可选的系统托盘后台常驻。
- 应用窗口、安装包、启动动画和系统托盘使用统一品牌图标；程序采用单实例运行，再次双击免安装版会唤起已有窗口而不是打开第二份应用。
- 资料完成后支持 10 秒掌握确认，为后续快速检测与动态复习路线积累低成本证据。
- 学习总览默认提供 6 项今日复习队列并显示每条建议的来源；知识图谱采用“课程 → 分批主题 → 来源资料”的分层浏览。
- 今日复习队列显示未开始、复习中、已复习待测试和最近测试正确率；任务可安排到具体日期，系统也会按最近掌握证据生成间隔复习日程。
- 设置中心可将每日复习队列调整为 3～12 项，并可单独开启或关闭每日一次的到期复习桌面提醒。
- 独立复习日程提供周视图、拖动改期和批量顺延/周末/指定日期/平均分散；同时保留掌握确认与快速测试历史，并提示单日任务负载。
- 设置中心提供 90%～140% 整体界面缩放；系统日程也可通过日期输入直接改期或忽略本次建议。
- 当学径长期没有记录到新的复习证据时，会提示日程可能与现实学习脱节，由用户选择重新安排或忽略旧建议，不擅自修改掌握状态。
- 周日程将待完成任务与历史证据分区展示；复习和测试历史默认折叠，不计入当天待办数量。
- 设置中心可将课程标记为已结课或重新开课。已结课课程停止进入自动复习队列、间隔日程和提醒，但仍可查看资料、知识库、自评、测试、成长与历史记录；平台再同步不会擅自恢复为进行中。
- 课程知识点同时展示主动自评与最近一次相关快速测试证据，包括正确率、覆盖题数、最近复习时间和证据状态。两类证据独立保存，出现矛盾时会明确提示而不是修改学生自评。
- 知识图谱通过颜色区分未形成证据、自评薄弱、测试薄弱、证据矛盾和测试验证较好，并可从知识点节点直接进入自选复习。
- 成长面板从启用当天开始保存每日状态快照，可按全部课程或单门课程查看最近 7/30 天的薄弱资料、待巩固知识点、验证较好知识点和证据矛盾变化。缺少记录的日期明确留空，不会伪造历史。
- 成长面板的课程证据默认收纳为 4 门课程，使用“展开全部/收起课程”查看其余课程，避免课程较多时页面过长。
- 使用 `Ctrl+K` 或侧栏搜索按钮打开全局搜索与快速操作中心，可统一查找课程、资料正文、知识点、作业与复习记录；输入 `>` 可只搜索命令。
- 应用内提供页面导航、Blackboard/Gradescope 同步、资料导入、知识库构建、番茄钟和手动作业快捷键。设置中心可以为每一项重新录制组合键、单独启用或禁用，也可恢复单项或全部默认配置。
- 快速测试错误任务只带入出错题对应的资料，不会自动展开关联知识点的其他来源课件；触发任务的旧测试分数也不会被误显示为本轮完成状态。
- 从今日队列点击“打开复习”会直接进入自选内容，不会把系统推荐原因误填为 AI 复习重点。
- 番茄钟专注与休息时长可在设置中调整，独立专注页和复习会话保持一致。
- 复习会话支持 3～10 题的自适应快速测试，可覆盖当前资料、本次会话已完成资料或最近薄弱内容，并保存来源、答案、评分和待覆盖内容；测试错误与未覆盖资料会回流今日复习队列。

## 开发与验证

```powershell
npm install
npm run dev
```

```powershell
npm test
npm run typecheck
npm run build
```

生成 Windows 安装包：

```powershell
npm run package:win
```

安装包输出到 `release/Xuejing-<版本号>-win-x64.exe`。开发和测试数据保存在当前 Windows 用户的应用数据目录与用户自行选择的资料库中。
