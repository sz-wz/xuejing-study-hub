# 知识条目筛选规则

知识库把“资料大纲”和“高置信知识条目”分开处理。只有高置信条目会进入后续的复习路径、作业前置知识和知识网络。

当前本地筛选会排除：

- 邮箱、网址、QQ群或其他联系方式；
- 讲师、授课单位、课程页眉页脚、日期、页码和 `Lecture #` 标记；
- 文件名、作业名称、课程介绍、目录、提示语和代码片段；
- 过长的英文句子、公式/图表文字等不适合作为知识标题的内容。

每一版筛选逻辑都有解析版本号。点击“构建 / 更新知识库”时，旧版索引会自动按最新规则重建；课程原文件不会被改动。

规则优先保证条目相关性，宁可漏掉边缘内容，也不把联系方式或课件杂讯当成知识。用户可在此基础上主动使用云端 AI 精炼，让模型为单份课件给出带来源证据的 3–8 个主题；精炼结果会替代该资料的规则候选主题参与课程知识点汇总，并有重复精炼保护。

后续仍可加入用户的“隐藏此条目”、合并同义知识点和跨课程概念确认反馈，以持续改善条目质量。
