# OCR 与云端 AI

## 本地 OCR

- 图片型 PDF 在知识库中显示“本地 OCR”按钮；点击后才开始识别。
- 选择一门课程后可使用“批量 OCR”处理该课程全部等待识别的扫描 PDF，并显示已完成、总数和失败数。
- PDF 页面在本机渲染并由 Tesseract OCR 在本机处理；不会上传扫描件。
- 中英文语言包随应用依赖提供，并复制到 Electron 用户数据目录的 OCR 缓存中，无需运行时从 CDN 下载。
- 单次 OCR 最多处理 30 页；超过部分会明确标记为截断，避免长教材占用过多时间和内存。

## 云端知识点精炼

- 在“知识库 → AI 设置”中填写 OpenAI 兼容的 API 地址、模型名和 API 密钥。
- API 密钥使用 Windows/Electron 系统安全存储加密保存；界面和知识索引都不会读取或展示明文密钥。
- 只有用户点击某一份资料的“AI 精炼”、课程级批量精炼、AI 复习规划或课程问答时，应用才会向云端发送相应资料的已提取文本（单份最多 60,000 个字符）、标题、课程名和本地候选主题。
- 云端结果必须返回带资料证据的 3–8 个知识点；这些知识点会替代该资料的规则候选主题参与课程知识点汇总。
- 教材/参考资料可以被 AI 精炼以便查看，但仍不会自动扩充课程知识点，除非用户将其改为课件。
- 单份和批量精炼都会显示阶段进度；应用记录资料内容指纹与精炼结果，避免同一版本资料被重复精炼。资料内容或解析结果改变后可再次精炼。
- AI 规划会尽量返回可验证的知识点和资料 ID，界面可一键应用到复习选择列表；模型只返回文字建议时，用户仍可手动修改最终选择。
- 作业分析中的 AI 匹配同样只在用户点击按钮时发起。请求包含 Blackboard 已读取的说明和/或手动导入作业文件在本地解析出的文本，以及当前课程可选知识点的标题/ID；模型只能返回给定 ID，结果必须由用户确认，系统不会以关键词、自评或“薄弱项”替代 AI 自动生成作业前置知识。Gradescope 作业不读取网页说明，改由用户在网页下载后手动导入文件。
