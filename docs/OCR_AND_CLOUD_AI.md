# OCR 与云端 AI

## 本地 OCR

- 图片型 PDF 在知识库中显示“本地 OCR”按钮；点击后才开始识别。
- 选择一门课程后可使用“批量 OCR”处理该课程全部等待识别的扫描 PDF，并显示已完成、总数和失败数。
- PDF 页面在本机渲染并由 Tesseract OCR 在本机处理；不会上传扫描件。
- 中英文语言包随应用依赖提供，并复制到 Electron 用户数据目录的 OCR 缓存中，无需运行时从 CDN 下载。
- 单次 OCR 最多处理 30 页；超过部分会明确标记为截断，避免长教材占用过多时间和内存。

## 云端知识点精炼

内置服务预设：

| 服务 | 默认 API 地址 | 官方说明 |
| --- | --- | --- |
| OpenAI / GPT | `https://api.openai.com/v1` | [OpenAI API 文档](https://platform.openai.com/docs/api-reference) |
| DeepSeek | `https://api.deepseek.com` | [DeepSeek API 文档](https://api-docs.deepseek.com/) |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | [Gemini OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai) |

预设只负责填写官方基础地址，实际模型名称始终从服务端模型列表读取或由用户填写。

- 在“知识库 → AI 设置”中可直接选择 OpenAI / GPT、DeepSeek、Google Gemini 或其他兼容 API；官方服务会自动填写基础地址，也可以手动修改。
- “获取模型”通过服务端 `/models` 动态读取模型，不在应用中硬编码过时列表。Gemini 的 OpenAI 兼容模型列表不可用时，会回退到 Google 原生 Models 接口。
- API 密钥使用 Windows/Electron 系统安全存储加密保存；界面和知识索引都不会读取或展示明文密钥。
- 用户界面只保留“本地构建 / 更新”和“AI 精炼”。能力检测会分别确认对话、文件与 Responses 端点：支持 Files + Responses 时优先直传整份原件；DeepSeek、Gemini 或仅支持 Chat Completions 的接口自动使用本地分页兼容精炼。
- 本地分页兼容流程保留 PDF 页和 PPTX 幻灯片编号，按页面组发送必要文本，最终跨组归并并校验页码。扫描页先使用本地 OCR；复杂图片、图表和无法提取的公式仍可能弱于真正的原件多模态分析。
- 即使能力探测判断可以直传，实际模型或文件格式仍可能拒绝输入。遇到 400/404/405/415/422/501 等文件能力错误时，该 API + 模型会在当前运行期间自动记为兼容模式，后续文件不再重复请求失败的上传端点。
- 云端结果必须返回带资料证据的 3–8 个知识点；这些知识点会替代该资料的规则候选主题参与课程知识点汇总。
- 教材/参考资料不进入 AI 精炼，只进行本地解析、搜索和阅读；用户将其改为课件后才允许精炼。
- 批量精炼作为非模态后台任务运行。原件直传在当前文件结束后形成安全点；分页兼容模式会保存页面组断点。立即停止会中断当前上传或分析，恢复时跳过已完成文件并复用可用断点；也可选择全部重新开始。应用按资料内容哈希保存各版本结果。
- 文件精炼结束后，课程级归并只发送标题、摘要、来源 ID 与页码元数据，不再次发送课件正文。低于 0.86 置信度、只有一个现有标题或相互重叠的分组会被忽略。
- 原件分析返回的页码/幻灯片范围会进行边界与置信度校验。置信度不低于 0.8 的范围直接用于定位，0.55～0.8 显示为待确认候选；用户可以确认、忽略、手动添加或删除范围。
- Files 或 Responses 接口不可用时不会再让批量任务逐份报相同错误，而是切换本地分页兼容精炼。未配置 API 时仍可完全离线运行本地构建、OCR、搜索和阅读。
- AI 规划会尽量返回可验证的知识点和资料 ID，界面可一键应用到复习选择列表；模型只返回文字建议时，用户仍可手动修改最终选择。
- 作业分析中的 AI 匹配同样只在用户点击按钮时发起。请求包含 Blackboard 已读取的说明和/或手动导入作业文件在本地解析出的文本，以及当前课程可选知识点的标题/ID；模型只能返回给定 ID，结果必须由用户确认，系统不会以关键词、自评或“薄弱项”替代 AI 自动生成作业前置知识。Gradescope 作业不读取网页说明，改由用户在网页下载后手动导入文件。
