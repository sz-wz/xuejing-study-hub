# 知识库分层策略

知识库不再把所有解析出的短文本直接当成同一层级的“知识条目”。

1. **资料级知识点**：每份课件最多保留 8 个候选主题，并能在知识库页面逐份展开查看。
2. **课程知识点**：只从标记为“课件 / 讲义”的资料级主题汇总，用于后续的复习路径、作业分析与知识网络。
3. **教材 / 参考资料**：仍在本地提取和保存，以便后续检索、引用和补充解释；默认不自动生成课程知识点，避免一本教材把数百页正文变成词条。

知识图谱直接使用这三层的来源关系：一份课件是资料节点，课程知识点是汇总节点，二者之间的边表示“此课件是该知识点的来源”。它不是凭关键词猜测出的关联网络，因此学生可以从期末复习的任一知识点回到真实课件。学生的 0–4 级自评单独保存为该课程知识点的学习状态，不会改写原始解析结果或 AI 精炼结果。

资料可在知识库页面切换“设为教材 / 改为课件”。手动导入时也可以预先选择用途。标题或目录含有 `textbook`、`reference`、`教材`、`教科书`、`课本`、`参考书` 的资料会自动作为参考资料处理。

## AI 的定位

规则负责离线提取、去除页眉页脚并提供不依赖云端的基础知识库；它无法稳定判断整份课件中哪些页面共同构成一个完整知识点。因此应用只保留两种用户可见操作：**本地构建 / 更新**与**AI 精炼**。AI 精炼由用户明确触发，内部根据 API 能力自动路由：支持 Files + Responses 时分析整份原件；仅支持对话时使用带真实页码的本地分页结构。两条路径都生成统一的 `original` profile，并使用 `analysisMethod` 区分 `original-file` 与 `structured-pages`。

文件级精炼完成后会进入课程级归并阶段。该阶段不重复上传课件全文，只发送知识点标题、摘要、来源资料 ID 和页码范围；仅接受置信度不低于 0.86、且确实包含两个以上现有标题的同义组。标准名与别名仅影响课程聚合图谱，资料级 AI 原始标题、证据和位置保持不变。教材默认只用于解释或验证已有知识点，只有用户主动将资料改为课件时才产生新的课程条目。

教材和参考资料只进入本地解析、全文搜索与阅读，不显示 AI 精炼入口，也不会进入批量精炼候选。用户只有先把它改为课件，才会允许原件精炼并参与课程知识点汇总。

批量精炼是主进程中的持久后台任务。原件直传以整份文件为安全单元；分页兼容模式以页面组保存检查点，因此可在安全断点暂停并继续。立即停止会中断当前网络请求，已完成文件与分页断点继续保留。旧版本 quick/deep profile 仅作为兼容历史保留，新的两种自动路由都写入统一 profile。

## 资料版本与来源冲突

- SHA-256 完全相同的文件视为相同内容，不重复参与知识聚合。
- 同一 Blackboard 资源且内容相近时，视为同一资料的不同版本，默认启用导入时间最新的版本，并允许在资料旁切换。
- 同一 Blackboard 资源如果出现不同章节编号（如 Part II 与 Part III）或内容差异很大，标记为“来源冲突”，不自动切换。
- 同名但 Blackboard 资源 ID 不同的文件保持独立，并使用章节标题或页数自动生成区分名称。
- 只有当前启用版本进入资料级与课程级知识聚合。各版本的 AI 结果按内容哈希分别保存，切回旧版本时可恢复该版本已有结果。
- 完全重复、未被课程资料和 manifest 引用的孤立副本只会列为安全清理候选，必须由用户确认后才删除。

## 页码与幻灯片级定位

知识点不再只能追溯到整份文件。解析器会在本地保留 PDF 页和 PPTX 幻灯片的文本边界；默认构建产生的本地候选主题会先尝试匹配具体页码。原件直传可直接返回连续或不连续页码范围；分页兼容流程使用本地页面编号约束模型输出。高置信度范围用于复习跳转，中置信度范围保存为待确认候选。

独立页级索引先为每页建立本地页面卡片，并统一 Unicode 数学字体、负号/破折号、希腊字母、异常空格和公式标点。检索综合使用标题、证据、数学公式 n-gram 和关键词；高置信度结果直接形成页码范围，中置信度结果只进入 `locationCandidates`，不会冒充已确认位置。

旧索引的独立页级补全能力继续作为兼容和内部修复工具保留，但不再作为用户可见的第三种精炼档位。连续页会合并成范围，不连续章节继续保留多段位置。

知识库分别显示“原件分析”和“知识定位”：前者使用模型报告的已检查页数计算覆盖率，后者表示多少知识点已有可信页码。用户可确认或忽略候选页，也可手动添加、删除范围。人工规则随同内容的资料库迁移和重新构建保留；文件内容哈希变化后不沿用旧规则，避免页码错位。没有可靠位置时，复习阅读器继续安全降级为打开整份资料。
